# Random baseline entry point

`main.py` is byte-identical to the entry point inside the tested Day 2 submission archive. It uses the standard library only and returns the official sample deck when asked, reading a local `deck.csv`.

The deck and generated archives remain outside Git. This checkout alone is not an uploadable package: copy the original official sample deck beside main.py, or use the locally preserved accepted archive. The required archive has main.py and deck.csv at its root. Run the Day 2 notebook for the complete packaging and verification sequence.
