# Official submission register

register.csv records screenshot-evidenced Complete submissions for the random baseline, heuristic and A-R1. It records A-R2 as upload_reported because the submitter reports uploading it but has not supplied a hosted result or screenshot. No A-R2 rating or acceptance status is invented.

The last supplied screenshot displays A-R1 828.8, heuristic 257.6 and random 11.5. These are historical rating snapshots. Existing histories remain unchanged until new evidence arrives. A-BASE/, A-HEUR-01/ and A-R1/ contain those images; A-R2/ contains the user upload report and local validation record.

Missing IDs, absolute timestamps, uncertainty and hosted A-R2 values remain blank. Local hashes identify tested files but cannot verify uploaded bytes. Generated archives, SDK binaries and official decks remain local. Original Colab not_submitted flags predate manual uploads and are not rewritten.

Track repairs separately and retain failed or ineffective attempts. A valid package, a user-reported upload, official acceptance and a rating observation are distinct evidence stages.
