## Reproduce and contribute

[Team workflow](CONTRIBUTING.md). Each team documents its runtime, dependencies, input files and execution commands. Official competition ZIPs, SDK binaries, decks, credentials and generated submission archives stay local. Selected measured results and fitted parameters are deliberately included for review and reproduction.

Both teams' reusable common Colab evaluation notebooks stay at their existing shared paths. Team A's [notebook index](team_a/notebooks/) separates the shared template from member-owned executed work. Its [shared command instructions](team_a/scripts/) distinguish individual-battle evaluation from the common match protocol.

Folders and branches organize work; they do not restrict repository readers. Follow the applicable competition sharing rules and record any required clarification. Repository visibility and collaborator permissions are not changed by this organization.
