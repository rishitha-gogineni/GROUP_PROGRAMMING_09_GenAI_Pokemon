Day 1 is the actual sprint start, not a fixed calendar date. Map these days to the confirmed course cutoff. The plan depends on a working SDK and a measured evaluation budget.

| Day | Work | Exit evidence |

| 4 | Complete remaining first models and second variants; three uploads per team; decide whether RL extensions continue | Every member has a trained first artifact; correct interfaces |

## Scope and gates

Core deliverables are small runnable architecture pairs and a reliable hybrid agent. Initially learn supported single-choice decisions; keep all other phases on a tested full-response handler. Log model/fallback coverage.

No full game on Day 1: prioritize official example/runtime. No valid baseline by Day 2: pause optional RL. No replay data by Day 2 morning: use own-team heuristic demonstrations. No correct RL loop by Day 4: stop the extension and report the trained warm-start objective accurately. A skeleton or failure record does not waive architecture/submission obligations.

Budget roughly 22-26 active hours per person, rebalanced daily, with unattended compute recorded separately. Start writing on Day 1. Measure match runtime before committing to evaluation counts; use small screens and a larger held-out finalist comparison.
